Adding real ads

  1. ACP → Extend → Widgets, pick a zone (Global Header, Sidebar or Global Footer).
  2. Drag in an HTML widget.
  3. Paste the ad snippet, drop your AdSense / sponsor code where marked, then Save.
  4. AdSense users: add the loader <script> once in Appearance → Custom HTML & CSS → Custom Header.

Install on NodeBB

  1. In the ACP, install the Harmony skin and set the default dark mode.
  2. Go to Appearance → Custom HTML & CSS, enable custom CSS.
  3. Paste the stylesheet, save, then rebuild & restart NodeBB.
  4. Upload the crest under Settings → General as the site logo and favicon.
